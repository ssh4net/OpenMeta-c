## Implemented correction

`omc_jumbf_limits.max_semantic_work` is appended to the public structure.
Initialization and zero normalization select a finite default of 1,048,576
units. A decode-context counter bounds traversal and existing semantic work;
exhaustion returns `OMC_JUMBF_LIMIT`. Existing collection/depth/storage limits
still apply. Accounting is specific to the C implementation: it does not
promise the same numeric exhaustion point as a different C++ algorithm.

Decompression clamps every caller write to the configured output cap. At the
cap, a one-byte private probe lets the decoder consume remaining framing;
producing another byte returns LIMIT without touching caller guard bytes.
The regression fails with the old library when a stored-deflate trailer arrives
through one-byte callback reads. Extraction and measurement now share exact-cap,
one-byte-over, short/zero-capacity and zero/unlimited behavior. Both optional
backends and nonzero callback source bases are exercised. Limit zero means
unlimited for all logical payload routes; the default remains 64 MiB.

BMFF rewriting rejects a retained `dimg` source losing a nonzero input during
managed-item remapping. Mixed ordered repeated targets survive two edits with
`iref` versions 0 and 1. Removing the source drops its relation. Direct and
serialized package materialization are tested on success and rejection.
Low-level rewriting retains pre-existing output on failure; package APIs reset
output first and publish no candidate. The source remains unchanged in either
case. Existing method-2/local-reference/meta-growth/media-preservation fixtures
are retained.

The internal EXIF writer retains its implicit empty-store no-op behavior, now
after bounded primary-directory validation. Classic TIFF and BigTIFF in LE/BE return
identical bytes for valid targets and reject incomplete/wrapped root counts
before copying. The result reports the detected format. This checks the root
table, not complete EXIF/image conformance. Active LE overlays already reject
oversized/wrapped root, ExifIFD and GPSIFD counts before arithmetic/allocation;
new tests retain those guards and missing-next-field cases. Their existing
65,535-entry ceiling remains. Active BE editing and an explicit C equivalent of
C++ `require_updates` remain UP6a work. This focused writer check does not
qualify every public transfer/package empty-edit route; their shared selected
edit policy remains part of that foundation.

The new `omc_test_resource_parity` compares enabled compression results and
guard bytes, plus valid/malformed optional TIFF no-op outcomes, with the pinned
C++ library. C's API default still differs from C++'s default empty-edit
rejection; the comparison explicitly sets C++ `require_updates=false`.

## Reproduction

Run from the workspace containing the sibling public repositories. Worktree
paths below are disposable and must not already contain a different checkout.

```sh
git -C OpenMeta worktree add --detach /tmp/openmeta-cpp-0.8.14-20261014 \
  fc2052b9eac0c7819c09a067e0c698fe38a2a155
cmake -S /tmp/openmeta-cpp-0.8.14-20261014 \
  -B /tmp/openmeta-cpp-baseline-0814-20261014 -G Ninja \
  -DCMAKE_CXX_COMPILER=clang++-20 -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH=/mnt/e/UBc/Release -DOPENMETA_USE_LIBCXX=ON \
  -DOPENMETA_BUILD_STATIC=ON -DOPENMETA_BUILD_SHARED=OFF \
  -DOPENMETA_BUILD_TESTS=ON -DOPENMETA_BUILD_TOOLS=OFF \
  -DOPENMETA_ENABLE_RAPIDFUZZ=OFF -DOPENMETA_WITH_DNG_SDK_ADAPTER=OFF
cmake --build /tmp/openmeta-cpp-baseline-0814-20261014 -j 6
ctest --test-dir /tmp/openmeta-cpp-baseline-0814-20261014 --output-on-failure

cmake -S OpenMeta-c -B /tmp/openmeta-c-0814-release-20261014 -G Ninja \
  -DCMAKE_C_COMPILER=clang-20 -DCMAKE_CXX_COMPILER=clang++-20 \
  -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=/mnt/e/UBc/Release \
  -DOMC_WARNINGS_AS_ERRORS=ON -DOMC_BUILD_PARITY_TESTS=ON \
  -DOMC_OPENMETA_DIR=/tmp/openmeta-cpp-baseline-0814-20261014 \
  -DOMC_OPENMETA_SOURCE_DIR=/tmp/openmeta-cpp-0.8.14-20261014
cmake --build /tmp/openmeta-c-0814-release-20261014 -j 4
ctest --test-dir /tmp/openmeta-c-0814-release-20261014 --output-on-failure

cmake -S OpenMeta-c -B /tmp/openmeta-c-0814-sanitizer-20261014 -G Ninja \
  -DCMAKE_C_COMPILER=clang-20 -DCMAKE_BUILD_TYPE=Debug \

ASAN_OPTIONS=detect_leaks=1 UBSAN_OPTIONS=halt_on_error=1 \
  ctest --test-dir /tmp/openmeta-c-0814-sanitizer-20261014 --output-on-failure
```
